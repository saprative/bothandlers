## Why

BotHandlers currently lacks a public-facing marketing presence. We need a landing page to explain the core value proposition ("PagerDuty for AI Agents", human-in-the-loop management platform) to prospective users and funnel them toward adoption.

## What Changes

- Create a new public marketing landing page in `apps/web`.
- Implement a dark, modern "vibe tech" aesthetic (inspired by robobrainstorm.com) to position BotHandlers as a cutting-edge AI infrastructure tool.
- Clearly articulate the core value proposition: Routing AI agent exceptions and policy boundaries to the right human operator.
- Add primary call-to-action (CTA) buttons to capture interest or lead to the application.

## Capabilities

### New Capabilities
- `marketing/landing-page`: Public-facing marketing landing page with the core value proposition and dark aesthetic.

### Modified Capabilities
- None

## Impact

- `apps/web`: Will introduce the public-facing marketing pages (e.g., `app/page.tsx` replacing or acting as the public landing instead of just the internal dashboard).
- No impact on the core Agentic Routing Engine or Backend APIs.
